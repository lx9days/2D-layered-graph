# 层内聚类分块

## 定义与实现

研究变量是节点相似性的标准；同一个层次凝聚聚类过程用于所有新标准。每层独立聚类，允许原始顺序不连续的节点属于同一块。每个节点初始为一个簇，每次合并平均跨簇节点对相似度最高的合法簇对。最高分低于阈值时停止，相同得分按输入枚举顺序确定，结果可复现。

入口：`src/lib/layout/multiRowCompact.ts`。特征和聚类：`src/lib/layout/multiRow/clustering.ts`。

- `neighbors`：沿用 0.45 入邻居加权 Jaccard + 0.45 出邻居加权 Jaccard + 0.10 加权度数相似度。
- `layer-profile`：分别将入邻居和出邻居聚合到语义层，使用跨度的 `spanExponent` 次方作为边权，并将每侧分布归一化。相似度是两侧加权 Jaccard 的平均值，不要求邻居 ID 相同。两侧都为空的分布相似度为 1，单侧为空为 0。
- `role`：入度、出度、入边占总度数比例、长边占关联边比例。前两项采用 `1 - abs(a-b)/max(1,a,b)`，后两项采用 `1 - abs(a-b)`，四项等权。度数使用边数量，独立于跨度权重。
- `legacy`：保留原有相似性序列化和动态规划连续分块，作为可切换基线。

默认标准为共同邻居，合并阈值为 0.65。为防止高相似度层合成过大的块，每簇节点数上限为 `max(4, round(sqrt(layerSize)*2.25))`，沿用旧分块的规模上限。阈值控制平均连接相似度，不保证簇内每个节点对都达到阈值。孤立节点具有相同的空邻域和角色，可以合并。

新聚类不使用多行预算决定成员归属；行数只在后续几何布局阶段使用。分块后仍进行块间重心排序、逆序修正、块内分行、坐标分配和局部布局优化。相同聚类参数传入无优化视图、有优化视图和行数采样。

## 验证与结论边界

`clustering.test.ts` 覆盖非连续成员合并、不同标准产生不同结果、接收与输出角色区分、平均连接避免单连接链式合并、规模约束与确定性、成员与行预算独立、语义层及输入保持、两侧视图参数一致。

这些检查证明机制符合定义，不证明任一标准能改善布局质量。后续评估应控制图、阈值、块规模约束和优化预算，报告块数量、宽度、实际路径交叉、总边长及优化增益。不同标准的相似度分布不同，相同阈值不等于相同聚类粒度；成员质量比较还需匹配块数量与大小。


## 新版 topology-strict（2026-11-18）
用户确认的新变体，默认启用；neighbors、layer-profile、role、legacy 保留作对照。
每层先按完整加权入、出邻居 ID 签名绑定，签名相同的节点不可拆分。
在全层候选中，仅当所有跨组节点对相似度都达到阈值时允许合并，再以节点对平均相似度择优。
普通合并遵循现有规模上限；初始同拓扑组可超过上限，不再因显示规模拆组。
成员确定后沿用块间排序、块内分行、坐标与局部优化。保证仅针对相同加权邻域和块内阈值，不保证所有跨块高相似节点同块，也不保证布局指标改善。
实现：clustering.ts、multiRowCompact.ts；界面：ControlPanel.tsx；默认：useDemoStore.ts。
验证：clustering.test.ts 增加两端同拓扑组超过大小上限且经最终布局仍完整、平均值掩盖低相似度反例、签名身份及顺序稳定性测试。


## 2026-11-19 阈值校准
连续切分使用综合代价，并未使用聚类阈值 0.65。平均连接与最低节点对准入的阈值不应直接复用。
新版 topology-strict 默认独立设为 0.05；其余对照保留 0.65，各策略单独记忆用户阈值。显式传入阈值优先。
保持相同拓扑绑定、最低节点对准入和规模限制；不引入随机分组，不改变相似度公式，不增加块间多行。
Medium（seed 71、6 行、跨度指数 2、关闭局部优化）校准：阈值 0.65 宽度 10150、第三层 192 块；0.05 宽度 1464、第三层 17 块。扫描 0.10/0.15/0.20/0.25 的宽度分别为 2768/4170/5470/7134。
此默认值是当前样例的工程校准，不代表所有数据的最优值，也不证明交叉或边长更优。0.05 是较弱的相似度下限，不能解释为块内高度相似。
回归测试覆盖默认 Medium 宽度、节点完整性、块横向单排以及切换策略的阈值独立性。


## 2026-11-19 层内自适应高度
按用户要求，topology-strict 不再将所有块初始化为最大行数。
每层先取节点数最多的块，在用户行数上限内枚举行数 r，以 abs(ceil(n/r)-r) 最小选择近方形排布；并列时优先较少行，避免竖条。当前几何的横纵间距、边距相同，所以该判据对应初始实际宽高差。
该行数成为本层上限；小块在此上限内各自选近方形行数，不强制填满。层高仍由最高块决定，块水平单排、垂直居中。相似性与块成员均不改变。对照策略保留旧行数分配。
用户行数设置是上限：过大的不可拆组可能仍然较宽。后续局部优化仍可调整块内节点，本规则定义初始排布而非新增硬性的正方形约束。
验证：rowAssignment.test.ts 覆盖近方形、并列偏宽、小块不撑满、空层及行数上限；原上下连接排序测试显式使用原版策略。

## 2026-11-20 两种实验相似标准

新增 multi-hop（多跳上下游分布）和 group-profile（群体连接分布）。均保持固定语义层、平均连接聚类、原规模上限和原版行分配；不使用 topology-strict 的绑定及最低节点对准入。默认阈值均为 0.65，分别记忆，尚未校准为最佳效果。

multi-hop：沿跨度加权并逐节点归一化的入/出邻接转移，计算恰好 1、2、3 跳的端点概率；死端概率消失，对每跳存活端点重新归一化用于比较。逐跳权重 1、0.5、0.25；使用加权 Jaccard，再按有效方向/跳数权重平均。双方均无该跳路径则跳过，只有单方为空则计 0，所有维度均空计 1。三跳为有界游走，允许有环，不是简单路径枚举。该标准比较上下游分布而非同层节点之间的可达性。

group-profile：先在每层按现有 neighbors 标准、固定 0.65 阈值及原规模上限产生参考群体；冻结群体身份，不迭代。然后将每个节点的直接入/出边跨度权重聚合到参考群体，分别归一化；两侧加权 Jaccard 等权平均，空分布规则沿用 layer-profile。UI 阈值只控制最终分块，不改变参考群体。参考群体不是语义真值，依赖初始共同邻居结构与输入顺序。

以上为论文启发的原型，不是 HOPE、DI-SIM 或 SBM 的复现。固定的跳数/衰减和参考阈值在此显式记录，当前 UI 仅暴露最终合并阈值。图较大时多跳稀疏分布可能变密，群体方案额外执行一次分层聚类。比较时应匹配块数/大小，并区分成员差异与 topology-strict 专属几何规则差异。

验证：新增间接公共终点、同层不同群体、两种标准的行预算独立性、语义层/输入保持、双视图集成与有限边长测试。机制检查不证明布局质量优于基线。
