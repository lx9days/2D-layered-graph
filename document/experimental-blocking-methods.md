# 两种实验分块模式与论文来源

更新日期：2026-11-23。

## 更新内容

Demo 目前显示共同邻居聚类（原版，默认）、多跳上下游分布、群体连接分布三个选项。其他模式暂时隐藏，保留实现供恢复与对照。本文说明新增模式的研究来源、实际规则和限制。

两个新模式是论文启发的实验设计，不是 HOPE、DI-SIM 或随机块模型的复现。它们改变节点相似性标准，仍在固定语义层内生成布局块，不改变 logical layer，也不直接把全图社区用作布局块。

## 共同流程

每层从单节点簇开始，以跨簇节点对平均相似度择优合并。仅合并达到阈值且合并后大小不超过 max(4, round(sqrt(layerSize) * 2.25)) 的簇；并列按输入顺序处理。允许原始顺序不连续的节点归为同块。平均连接不保证每个节点对均超过阈值。

两种模式默认最终合并阈值均为 0.65，界面分别记忆。阈值未经过布局效果最优校准；不同标准使用相同阈值，不代表相同粒度。成员归属与行数预算、几何位置无关，后续沿用块排序、原版行分配及局部优化。不采用 topology-strict 的同拓扑绑定与最低节点对准入。

直接边权为 max(1, abs(targetLayer-sourceLayer)) 的 spanExponent 次方，多条同端点边累加。加权 Jaccard 为各维度最小值之和除以最大值之和。

## 多跳上下游分布（multi-hop）

### 研究动机与来源

HOPE 强调高阶非对称邻近关系及 source/target 表示。本模式借鉴“不能只考虑一跳邻居”和“区分输入输出方向”，将其改编为可解释的有限跳端点分布。

来源：Mingdong Ou, Peng Cui, Jian Pei, Ziwei Zhang, Wenwu Zhu. **Asymmetric Transitivity Preserving Graph Embedding**. KDD 2016, 1105–1114.

作者论文：https://zw-zhang.github.io/files/2016_KDD_HOPE.pdf

### 实际计算

1. 分别构造沿出边前进与沿入边反向追溯的转移矩阵，每个节点的转移权重归一化。
2. 从节点自身出发，计算恰好 1、2、3 跳的端点质量分布。死端的质量消失；用于比较时，每跳存活端点重新归一化。
3. 每个方向、每个跳数分别计算端点分布的加权 Jaccard。
4. 跳数权重依次为 1、0.5、0.25，对有效方向/跳数维度加权平均。
5. 双方该维度均为空则跳过，单方为空计 0；全部维度为空时相似度为 1。

这是有限长度游走，可经过循环，不是简单路径枚举。当前跳数与衰减固定在代码中，UI 仅提供最终合并阈值。

例如 u→a→t 与 v→b→t 中，u、v 的直接下游不同，但二跳下游相同，因此获得额外相似证据。同层节点不必互相可达。

### 与 HOPE 和原版的区别

本实现不执行低秩矩阵分解、不训练 embedding，也不直接使用 HOPE 的高阶邻近矩阵。原版比较直接邻居 ID 和加权度数，本模式比较多个尺度的端点分布，且不额外加入度数项。双方空维度的处理也与原版不同，实验中需要区分这些因素。

风险：远处公共汇点可能造成过度相似；存活质量归一化不保留到达该跳的总概率；高阶分布可能变密并增加计算成本。高阶结构相似不保证直接边交叉更少。

## 群体连接分布（group-profile）

### 研究动机与来源

DI-SIM 将发送与接收角色分开考虑，随机块模型通过群体间连接模式解释节点结构。本模式借鉴“连接到哪些群体”，在具体邻居 ID 与粗粒度语义层之间引入中间粒度。

主要来源：Karl Rohe, Tai Qin, Bin Yu. **Co-clustering directed graphs to discover asymmetries and directional communities**. PNAS 113(45), 12679–12684, 2016.

论文：https://doi.org/10.1073/pnas.1525793113

补充概念来源：Tiago P. Peixoto. **Hierarchical Block Structures and High-resolution Model Selection in Large Networks**. Physical Review X 4, 011047, 2014.

论文：https://arxiv.org/abs/1310.4377

### 实际计算

1. 在所有语义层内运行现有 neighbors 平均连接聚类，参考阈值固定为 0.65，沿用共同规模上限。
2. 冻结参考群体身份，不进行反馈迭代。各层群体具有独立 ID。
3. 对每个节点，将直接入边与出边权重分别按邻居所属参考群体累加，并分别归一化。
4. 最终相似度为 0.5 × 输入群体分布 Jaccard + 0.5 × 输出群体分布 Jaccard。
5. 某方向双方均为空时该方向计 1，单方为空计 0。

UI 阈值仅影响最终分块，不影响第一阶段参考群体。

例如 u 和 v 指向不同节点，但这些邻居属于同一参考群体，则 u、v 可以获得相似性。若 w 指向同一语义层中的另一群体，它可以被区别出来。

### 与来源方法和原版的区别

本实现没有 DI-SIM 的谱分解与双重群体推断，没有 SBM 的概率生成模型、似然或描述长度优化，也不产生嵌套 SBM。最终每个节点仍只属于一个层内布局块。

原版依赖邻居 ID 重合，本模式依赖参考群体重合；当前 role 模式只用度数等统计量，也不同于这里的群体连接角色。参考群体若大多为单节点，新标准的收益可能有限，但由于归一化和度数项不同，也不严格等同于原版。

风险：参考群体依赖第一阶段阈值、规模上限和输入顺序，并不代表真实语义群体；第一阶段误差可能传递到第二阶段；固定参考群体避免了迭代，但不能联合优化整个划分。

## 使用与评估

在“分块标准”选择相应实验模式，调整“聚类合并阈值”观察变化。建议先固定图和优化预算，关闭局部优化比较初始分块，再开启优化比较最终布局。比较阈值扫描时需同时记录块数量和大小，不能仅比较同一数值阈值下的宽度。

关注节点是否聚集出预期结构，同时检查宽度、路径交叉、总边长与运行时间。结构解释性和布局收益是两个不同问题。
